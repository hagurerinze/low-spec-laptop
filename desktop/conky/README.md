Conky Setup
A simple collection of my personal Conky configurations.

Requirements
- Conky (obviously)
- A *font* that supports nerd symbols (optional, but looks better)

How to Use
1. Clone this repository to your local machine.
2. Move your chosen Conky config folder to `~/.config/conky/`.
3. Run it from your terminal using: (paths may be different check by yourself)
   `conky -c ~/.config/conky/your_config_name.conf`

Notes
Adjust the network interface and monitor paths inside the script to match your hardware.

Layout Notes
- *Center*: Used by XFCE and BSPWM (check `xfce-bspwm-center.conf`).
- *Right*: Used by XFCE and BSPWM (check `xfce-bspwm-right.conf`).
